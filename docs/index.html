Getting Started

one.css is a tiny, classless stylesheet with light & dark themes and custom accent colors.

Installation

You can install one.css via npm or use a CDN.

Directly

<link rel="stylesheet" href="one.css">

CDN (full bundle)

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rhenryw/one.css@main/dist/one.min.css">

CDN (ultra-light classless bundle)

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rhenryw/one.css@main/dist/one.light.min.css">

Use one.light.min.css for drag-and-drop HTML when you want the smallest payload and only core classless styling + light/dark theme support.

Bundle Comparison

Bundle Includes Best For
one.min.css Full system: classless base + components + advanced form styling Apps/sites that use the full one.css feature set
one.light.min.css Ultra-light classless core + light/dark theming Drag-and-drop HTML and minimal payload pages

Usage

Simply include the stylesheet in your HTML. There are no build steps required if you use the distribution file.

Basic Template

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My Awesome Site</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rhenryw/one.css@main/dist/one.min.css">
  </head>
  <body>
    <header>
      <h1>Hello, world!</h1>
      <nav>
        <a href="#">Home</a>
        <a href="#">About</a>
      </nav>
    </header>
    <main>
      <p>Start building your site with semantic HTML.</p>
      <button>Click me</button>
    </main>
  </body>
</html>

Features

  • Classless: Works with raw, semantic HTML.
  • Theming: Automatic light/dark mode support.
  • Customizable: Single CSS variable --accent controls the entire theme color.
  • Responsive: Mobile-first typography and layout utilities.
  • Icons: Uses standard SVGs or emojis, no icon font dependency.
