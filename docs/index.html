Getting Started

one.css is a tiny, classless stylesheet with light & dark themes and custom accent colors.

Installation

You can install one.css via npm or use a CDN.

Directly

<link rel="stylesheet" href="one.css">

CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rhenryw/one.css@main/dist/one.min.css">

Usage

Simply include the stylesheet in your HTML. There are no build steps required if you use the distribution file.

Basic Template

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My Awesome Site</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rhenryw/one.css@main/dist/one.min.css">
  </head>
  <body>
    <header>
      <h1>Hello, world!</h1>
      <nav>
        <a href="#">Home</a>
        <a href="#">About</a>
      </nav>
    </header>
    <main>
      <p>Start building your site with semantic HTML.</p>
      <button>Click me</button>
    </main>
  </body>
</html>

Features

  • Classless: Works with raw, semantic HTML.
  • Theming: Automatic light/dark mode support.
  • Customizable: Single CSS variable --accent controls the entire theme color.
  • Responsive: Mobile-first typography and layout utilities.
  • Icons: Uses standard SVGs or emojis, no icon font dependency.
